# JavaFX Timesheet Manager

A desktop timesheet application built with Java SE 25 and JavaFX 26.0.1. The app helps users enter, save, filter, export, and email weekly timesheet entries.

## Features

- Add and remove timesheet entries
- Employee and job site dropdown history
- Clock in / clock out picker with AM/PM support
- Lunch deduction support
- Weekly local file saving
- Filter by employee, job site, and week
- Export as CSV, TXT, or Excel spreadsheet
- Email export workflow
- Unsaved changes warning before exit

## Tech Stack

- Java SE 25
- JavaFX 26.0.1
- Maven
- Apache POI for Excel export
